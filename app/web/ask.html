Type a question the way you would ask it. "How many laptop repairers are there in Nakawa?" or "where can I get a phone screen replaced in Kampala Central". It resolves the subject and the place against the directory, then shows you exactly how it read the question, so a wrong answer is visible as a misreading rather than hidden behind a list.

    Questions are recorded as anonymised demand signals, exactly as a search from the directory is. The reading is done on this machine: nothing about your question is sent anywhere else.

    How it reads a question

    It looks for one place, using the real administrative geography, and one subject, using the real category tree. Anything it does not recognise is kept as free text, so an unfamiliar place or trade narrows the search instead of being quietly dropped. A question that opens with "how many" is answered with a number; anything else returns matching listings. The whole reading is in /api/v1/ask.
